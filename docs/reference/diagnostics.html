Diagnostic codes

The stable codes of diagnostics. Search for a code on this page or run yassb docs diagnostics.

CodeMeaningReported by
CONFIG_LOAD_FAILEDThe configuration (config/*.ts|js|json) or a module it imports threw while loading.behaviour.site-code, config.files
CONFIG_MODULE_NOT_FOUNDThe configuration imports a package that is not installed in the site.config.files
CONFIG_UNSUPPORTED_FILEA config file has a format YASSB 2 does not read (yaml, toml, …).config.files
UNDECLARED_DEPENDENCYSite code imports a package missing from package.json (it may work only by accident).cli.check
COMPONENT_NOT_FOUNDA `component` directive points to a file that does not exist.directive.component
COMPONENT_UNSUPPORTED_FORMATA `component` directive points to a file type that cannot be included.directive.component
COMPONENT_CYCLEComponents include each other endlessly.directive.component
DATA_SOURCE_MISSING_NAME`create-from-data-source` has no file name.directive.create-from-data-source
DATA_SOURCE_NOT_FOUND`create-from-data-source` points to a JSON file that does not exist.directive.create-from-data-source
DATA_SOURCE_INVALID_JSONA data source is not valid JSON.directive.create-from-data-source
OPTIONS_INVALID_JSONThe `options` attribute of a directive is not valid JSON.directive.attributes
RENDERER_MISSINGA directive has no `renderer` attribute; `basicElement` is used.api.custom-renderers
RENDERER_NOT_FOUNDThe renderer named in a directive is not registered in `customRenderers`.api.custom-renderers
RENDERER_FAILEDA renderer threw an exception.api.custom-renderers
DIRECTIVE_NO_REGEXA custom directive class has no static `regex`.api.custom-directives
DIRECTIVE_FAILEDA custom directive threw an exception or returned no HTML.api.custom-directives
DIRECTIVE_UNPROCESSEDA directive is still in the page after processing; its content is missing.behaviour.pipeline
URL_TO_EMPTY`url-to` has no value.directive.url-to
URL_TO_NOT_FOUND`url-to` matches no file of the site.directive.url-to
URL_TO_AMBIGUOUS`url-to` matches several files; the closest one is used.directive.url-to
PUBLIC_FILE_LIST_RENDERER_NOT_FOUND`public-file-list` needs a renderer registered in `customRenderers`.directive.public-file-list
PUBLIC_FILE_LIST_NOT_FOUND`public-file-list` points to a folder that does not exist in the output.directive.public-file-list
TEMPLATE_NO_DIRECTIVEA file in pages-to-generate has no `generate-from-files` directive.directive.generate-from-files
TEMPLATE_SOURCE_NOT_FOUNDThe folder of a `generate-from-files` directive does not exist.directive.generate-from-files
MARKDOWN_EMPTYA Markdown/text file used to generate a page is empty.content.markdown, directive.generate-from-files
FRONT_MATTER_INVALID_DATEA `date` front matter value is not a valid date.content.front-matter
I18N_MISSING_KEYA translation key is used in a page but missing in a language file.i18n.translation
I18N_INVALID_FILEA language file in the i18n folder is not valid JSON.i18n.translation
I18N_UNCLOSED_ELEMENTAn element with `data-t` has no closing tag, so it was not translated.i18n.translation
I18N_UNTRANSLATED_ATTRIBUTEA `data-t`/`data-attr-t` attribute is left in the output.cli.check
I18N_UNUSED_KEYA translation key is never used in the sources (it may be used by code).cli.check
I18N_INCONSISTENT_KEYSA translation key exists in some languages but not in others.cli.check
POST_PROCESSOR_FAILEDA post processor threw an exception.config.postProcessors
HOOK_FAILEDA beforeBuild/afterBuild hook threw an exception.config.afterBuild, config.beforeBuild
OUTPUT_LOCKEDAnother YASSB process (build, check or watch) is writing the same output folder; nothing was written.behaviour.output-lock
BUILD_CRASHEDThe build process stopped unexpectedly (watch mode keeps serving the last output).cli.watch
MINIFY_FAILEDThe HTML minifier could not parse a page; the page was written unminified.config.htmlMinificationOptions
STYLES_FAILEDThe stylesheet could not be compiled.assets.styles, config.stylesParser
SCRIPTS_FAILEDThe scripts could not be bundled.assets.scripts, config.webpackConfig
LINK_BROKENA page links to a local file that is not in the output.cli.check
UNUSED_COMPONENTA component is not used by any page.cli.check
UNUSED_DATA_SOURCEA data source is not used by any page.cli.check
